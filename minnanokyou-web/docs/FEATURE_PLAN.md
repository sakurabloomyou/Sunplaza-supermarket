# 機能の追加計画（ステージ・受け身の利用・通知・レポート・有料メニュー）

作成：2026年11月16日

## 1. 今回 Web 版に入れたもの（試作・お試しモードで動作確認済み）
| 機能 | 内容 |
|---|---|
| **ステージ（3段階）** | 初回設定の「ご本人の今の様子」で選ぶ。1：もの忘れが気になる程度／2：予定を忘れることが増えた／3：声かけがあれば過ごせる。ステージでご本人の使い方が変わる |
| **受け身の利用（ステージ3）** | ご本人の画面から「済み」ボタンをなくし、記録は家族が行う。「置き型ボード」で、ご本人は見るだけ |
| **置き型ボード** | 大きな時計・いま・つぎ・きょうのみんな。ごはん・おくすりの時刻、お迎えの1時間前・お迎え・帰宅の時刻に、画面いっぱいのお知らせ＋チャイム＋読み上げ（5分で消える）。画面を消さない設定（Wake Lock）に対応 |
| **記録のレポート** | 1週間／1か月。記録の割合、遅れ・未記録、ごはん・おくすり別の割合と平均のずれ、記録した人（分担のかたより）、デイの日に持ち物がそろった日数。文字でコピー・印刷/PDF。月曜日（または7日ごと）に家族のホームで知らせる |

ステージの区切りは目安。対象の目安（日常生活自立度 Ⅰ〜Ⅱa 程度）との対応は研究者の確認が必要。

## 2. 「アプリを開かなくても分かる」の選択肢
| 方法 | 開いていないときに届くか | 費用 | ご本人の操作 | 状態 |
|---|---|---|---|---|
| **A. 置き型ボード（Web版）** | 画面を開いたままにしておけば、時刻に声と画面で知らせる | 0円 | なし | **できた** |
| **B. iPhoneアプリのローカル通知＋ロック画面ウィジェット** | 届く（サーバー不要。端末の中で時刻に通知） | 公開には Apple Developer Program 年99米ドル。試作は無料の Apple ID で7日ごとに入れ直し | なし（ロック画面に表示） | 通知はコード済み。ウィジェットは未実装 |
| **C. Web版のプッシュ通知** | 届く（iOS 16.4 以降、ホーム画面に追加した場合） | Firebase を従量課金（Blaze）にして、時刻に送るしくみ（Cloud Functions＋Firebase Cloud Messaging）が必要。無料枠あり、クレジットカード登録が必要 | なし | 未実装 |

おすすめの順番：**A を今すぐ使う → Phase 2 で B（App Store）→ Web版を続けるなら C**。
C の月額は利用量で決まるため、Phase 0 の利用データで試算する（確認できていない）。

## 3. 有料メニューの見直し（決めるための案）
前提：安全に関わる機能（時刻のお知らせ、済み、ご本人の画面、ステージ）は無料のまま。広告は入れない。

| 機能 | 案1：個人に課金 | 案2：企業・自治体だけに課金 | 案3：ずっと無料（企業の収入でまかなう） |
|---|---|---|---|
| 置き型ボード（声・画面のお知らせ） | 無料 | 無料 | 無料 |
| 1週間のレポート | 無料 | 無料 | 無料 |
| 1か月以上のレポート・推移・受診用PDF | **有料** | 企業契約で無料 | 無料 |
| 閉じていても届く通知（C。サーバー費用がかかる） | 基本は無料／細かい時刻設定・家族全員への通知は**有料** | 企業契約で無料 | 無料 |
| 家族10人・ご本人2人 | **有料** | 企業契約で無料 | 無料 |
| 写真カード・声メッセージ | **有料** | 企業契約で無料 | 無料 |
| 企業向け：個人が分からない利用状況の集計レポート | — | **有料（企業）** | 有料（企業） |

決めるときに確かめること：
- 支払う意向（Phase 0 の聞き取り）。
- 1人の支払いで家族全員が使える形が App Store の決まりに合うか（確認できていない）。
- レポートは「診断や治療の判断に使うものではない」と表示し続ける（医療機器とみなされないように）。
