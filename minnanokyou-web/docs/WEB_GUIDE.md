# 無料の Web アプリ版を公開する手順

作成：2026年11月15日。お金をかけずに、家族数組に試してもらうための手順です。

## まず知っておいてほしいこと
| 項目 | 内容 |
|---|---|
| 費用 | Firebase の無料プラン（Spark）の範囲なら 0円。クレジットカードの登録は不要 |
| 無料の上限（出典：https://firebase.google.com/pricing 2026年11月時点で検索） | データの読み込み 1日5万回、書き込み 1日2万回、公開するファイル 10GB・転送 1日360MB。数家庭の試用なら足りる見込み（実際の使用量で要確認） |
| できること | 初回設定（悩みを選ぶ）、家族のホーム（済みチェック・お迎え・持ち物・記録・分担）、ご本人の画面、8けたの招待コードで家族の間で共有 |
| **できないこと** | **アプリを閉じているときのお知らせ**（予定の時刻に通知を送るにはサーバーで動くしくみが必要で、無料プランでは作れないため。開いている間は画面が1分ごとに新しくなる） |
| データの置き場所 | Google の Firebase（運営者が作ったプロジェクト）。**iPhone アプリ版と違い、健康に関わる情報を運営者側で預かる**ことになる。プライバシーポリシーをこの形に合わせて書き直し、法務の確認を受けること |
| iPhone での使い方 | Safari で開き「ホーム画面に追加」して、**ホーム画面のアイコンから開く**（Safari のままだとデータが別になる） |

## 1. お試しモードで見てみる（任意・Firebase なし）
`public/firebase-config.js` が空（`{}`）のままだと、この端末の中だけに保存する「お試しモード」で動きます。手順3〜5を先にやって公開すれば、スマホで見た目を確かめられます（家族の招待はできません）。

## 2. Google アカウントを用意する
ふだんの Gmail などで可。

## 3. Firebase のプロジェクトを作る（ブラウザで操作）
1. https://console.firebase.google.com を開き、「プロジェクトを作成」。
2. 名前：例 `minnanokyou-trial`。Google アナリティクスは「オフ」でよい。
3. できたら、左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」→ **</>（ウェブ）** を押す。
4. アプリのニックネーム：`みんなのきょう Web`。「Firebase Hosting も設定する」にチェック →「アプリを登録」。
5. 表示される `const firebaseConfig = { apiKey: ..., authDomain: ..., projectId: ..., ... };` の **{ } の中身**をコピー。
6. `minnanokyou-web/public/firebase-config.js` を開き、`export const firebaseConfig = {};` の `{}` を、コピーした `{ ... }` に置き換えて保存。
   （この値は公開されても問題ないものです。データは手順5の「ルール」で守ります）

## 4. ログインのしくみを有効にする
1. 左のメニュー「構築」→「Authentication」→「始める」。
2. 「Sign-in method」タブ →「**匿名**」→「有効にする」→ 保存。
   （利用者にメールアドレスなどを入れてもらわずに、端末ごとに見分けるため）

## 5. データベースを作る
1. 左のメニュー「構築」→「Firestore Database」→「データベースを作成」。
2. 場所：**asia-northeast1（東京）**。
3. 「本番環境モードで開始」を選んで作成。
   （ルールは次の手順で、このフォルダの `firestore.rules` をアップロードします）

## 6. パソコンに道具を入れる（Mac / Windows どちらでも）
1. https://nodejs.org から「LTS」版をダウンロードしてインストール。
2. ターミナル（Windows は「コマンドプロンプト」）で、Firebase の道具を入れる：
```bash
npm install -g firebase-tools
```
3. Firebase にログイン（ブラウザが開くので、手順2の Google アカウントで許可）：
```bash
firebase login
```

## 7. 公開する
1. ターミナルで `minnanokyou-web` フォルダに移動（`cd ` の後にフォルダをドラッグして Enter）。
2. 手順3で作ったプロジェクトを選ぶ（一覧から選び、別名は `default` と入力）：
```bash
firebase use --add
```
3. 画面とデータのルールを公開：
```bash
firebase deploy --only hosting,firestore:rules
```
4. 最後に表示される `Hosting URL: https://（プロジェクト名）.web.app` が、アプリの住所です。

## 8. スマホで使い始める
1. iPhone の **Safari** で、手順7の URL を開く。
2. 下の共有ボタン（四角から上向きの矢印）→「**ホーム画面に追加**」→「追加」。
3. **ホーム画面の「みんなのきょう」アイコンから開く。**
4. 「家族として始める」→ 初回設定 →「ホームへ進む」。
5. 家族のホームの「家族を招待する」→「招待コードを作る」→「コードと説明をコピー」して、LINE などで家族に送る。
6. 家族・ご本人は、同じ URL を開いて手順2〜3（ホーム画面に追加して、アイコンから開く）→「招待コードを入力する」→ 8けたを入れて「ご本人として」または「家族として」→「参加する」。

## 9. 直したものを反映するとき
コードを取り直して `public/firebase-config.js` に設定を入れ直し、手順7の3（`firebase deploy ...`）をもう一度。開いているスマホは、開き直すと新しくなります。

## 困ったとき
| こんなとき | 原因と対処 |
|---|---|
| 「お試しモード」と表示される | `public/firebase-config.js` が空のまま公開されている。手順3の6と手順7の3をやり直す |
| 招待コードを作れない／参加できない | 手順4（匿名ログイン）と手順5（データベース）、手順7の3（ルールの公開）ができているか確認 |
| 家族グループが消えた | Safari で開いた／ホーム画面のアイコンを消した／ブラウザのデータを消した可能性。家族に新しいコードを作ってもらい、もう一度参加する（記録は家族グループに残っている） |
| 無料の上限に近づいた | Firebase の「使用量と請求額」で確認。上限を超えるとその日は使えなくなる（自動で課金はされない） |

## 次の段階（費用がかかるもの）
- **閉じているときのお知らせ**：Firebase を有料の従量課金プラン（Blaze。クレジットカード登録が必要。無料枠あり）にして、決まった時刻に通知を送るしくみ（Cloud Functions と Firebase Cloud Messaging）を加える。iPhone では iOS 16.4 以降、ホーム画面に追加した場合だけ届く（出典：https://firebase.blog/posts/2023/08/fcm-for-safari 、https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados ）。
