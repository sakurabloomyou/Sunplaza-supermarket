# みんなのきょう（Web アプリ版）

ホーム画面に追加して使う Web アプリ（PWA）。iPhone アプリ版（`../minnanokyou-ios`）と同じ画面のしくみで、無料の Firebase で家族の間の共有ができる。

- 公開の手順：**`docs/WEB_GUIDE.md`**
- 画面：`public/index.html`、`public/app.js`、`public/app.css`
- データ：`public/store.js`（Firebase の設定が空ならこの端末だけの「お試しモード」）
- データのルール：`firestore.rules`（家族グループのメンバーだけが読み書きできる。参加は有効期限24時間・8けたの招待コード）

## 確認したこと（2026年11月15日）
- お試しモード：初回設定 → 家族のホーム → 済みチェック → ご本人の画面 → 記録 → 分担表の追加・引き受け、を自動操作で確認
- Firebase モード：Firebase エミュレーター上で、3つのブラウザ（家族・ご本人・部外者）を使って確認
  - 家族が招待コードを作り、ご本人がコードで参加できる
  - まちがったコードは「見つかりませんでした」と断られる
  - 部外者は家族グループの一覧を読めない（ルールで拒否）
  - ご本人の「済み」が家族の記録に、家族の「済み」がご本人の画面に、すぐ反映される
- 本物の Firebase プロジェクトと実際の iPhone では、まだ確かめていない
