# 忘年会2026 LP セットアップ手順

構成：**Googleフォーム（事前アンケート）→ Googleスプレッドシート → Apps Script（LP配信・回答ロック・正解発表）**
すべて無料のGoogleアカウントで動きます。参加者はログイン不要でURLを開くだけです。

| ファイル | 役割 |
|---|---|
| `index.html` | LP本体（ブラウザで直接開くとデモモードで動作確認できます） |
| `Code.gs` | Apps Script のサーバー処理（フォーム作成・回答の保存・1人1回ロック・集計） |

## 1. スプレッドシートとスクリプトを用意（幹事・10分）
1. Googleドライブで新しいスプレッドシートを作成（名前は「忘年会2026」など）
2. メニュー **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身を全部消して、`Code.gs` の内容を貼り付け
4. 左の「＋」→ **HTML** → 名前を `index` にして、`index.html` の内容を貼り付け
5. 保存

## 2. 事前アンケート（フォーム）を作成
1. Apps Script 上部の関数選択で `setAdminPin` を選ぶ（先にコード内の `'1230'` を好きなPINに変更）→ **実行**（初回は権限の許可が出るので許可）
2. 関数 `setupForm` を選んで **実行**
3. 「実行ログ」に表示される **回答用URL** をLINEでみんなに送る（**締切：12月27日（日）23:59**）
   - 12/28 0:00 に自動で受付終了します（フォームの説明文にも締切を記載済み）。延長したいときはフォーム編集画面の「回答」タブで受付を再開
   - 質問：①名前（選択式）②2026年の個人的大ニュース ③当日話したいエピソード（任意・LPには非表示）
   - 回答はスプレッドシートの「フォームの回答 1」シートに自動で入ります

### フォームの文言を直したいとき（作成済みのフォーム）
`Code.gs` 冒頭の「アンケートの文言」を直して保存 → 関数 `updateForm` を **実行**。フォームのURL・集まった回答はそのままで、タイトル・説明文・質問の文言だけ更新されます。

## 3. LPを公開
1. Apps Script 右上 **デプロイ → 新しいデプロイ** → 種類「ウェブアプリ」
2. 次のユーザーとして実行：**自分** / アクセスできるユーザー：**全員**
3. 発行された **ウェブアプリURL** を参加者に共有（開催案内・メンバー紹介はこのURLで見られます）
4. 幹事用は URL の末尾に `?admin=1` を付けて開く（例：`https://script.google.com/macros/s/xxxx/exec?admin=1`）→ 幹事パネルまで自動スクロール → PIN でログイン
   - うまく出ないときは、ページ最下部の「忘年会2026 実行委員会（幹事）」の文字を**素早く5回タップ**しても幹事パネルが出ます

> コードを修正したら「デプロイ → デプロイを管理 → 編集 → バージョン：新バージョン」で更新（URLは変わりません）。

## 4. 当日の進行
幹事用URL（`…/exec?admin=1`）を開くと **幹事画面だけ** が表示されます。幹事もクイズに参加する場合は「参加者画面へ」で切り替え、右上の「幹事画面へ」で戻れます。

1. アンケート締切後、幹事画面の「準備」→ **「フォームの回答から問題を作成」**（出題順はシャッフル）
2. 参加者は各自スマホでLPを開き、クイズ欄で **自分の名前** を選ぶ
3. 幹事画面の **「次の問題を出題」** → みんな「この人だ！」と思う名前を選んで **決定**（確認後は変更不可）
   - 回答人数は「回答 ◯ / 11人」とバーで表示。答えは「こっそり答えを見る」を押したときだけ表示
4. 揃ったら **「正解発表する」** → 全員の画面に正解と◯✕・みんなの予想が出る（約4秒で自動更新）→ 本人に解説してもらう
5. 12問終わったら、幹事画面の「いまの上位」で1位を発表 → プレゼント贈呈

- 正解発表できるのは出題中の問題だけ、同時に出題できるのは1問だけです（押し間違い防止）
- 問題ごとの操作（個別に出題／未出題に戻す）は「問題一覧」から

## ルールの実装
- 回答は **サーバー側で1人1問1回** に制限（同時アクセスはロックで保護）。2回目はエラーで拒否
- 正解発表後・出題前の問題には回答不可
- 本人の名前は **正解発表までブラウザに送られない** ので、ページのソースを見てもカンニングできません
- 同点1位はじゃんけんで決定（LPには記載なし。当日アナウンス）

## カスタマイズ
`index.html` の `<script>` 冒頭「ここを幹事が書き換える」欄で設定します（空欄のままでも表示は崩れません）。

| 設定 | 内容 | 空欄のとき |
|---|---|---|
| `FORM_URL` | アンケートの回答用URL（12/27までページ上部にボタン表示） | 「LINEで送ったフォームから答えてね」 |
| `KANJI` | 幹事の名前（フッター） | 「幹事より」 |
| `MEET` | 待ち合わせ場所・時間 | 「待ち合わせはLINEで決めよう。」 |
| `PAIRS` | 夫婦の組み合わせ `['妻','夫']` | 「高校の7人」「だんなさんたち」で表示 |
| `MEMBERS[].hito` | カードに出すひとこと | 非表示 |

- イラスト・キャラ名（マジカル・ハート等）・色：`index.html` の `MEMBERS` 配列
- 名前の表記を変える場合は、`index.html` の `MEMBERS` と `Code.gs` の `MEMBERS` の両方を同じ表記に揃える
