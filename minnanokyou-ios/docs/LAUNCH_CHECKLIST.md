# ローンチまでの手順（チェックリスト）

作成：2026年11月12日。☑ はこちらで用意済み、☐ はこれから。担当は README のチーム表の役割。

## A. 先に決めること（ここで止まると申請できない）
- ☑ **申請は個人で行う方針**（2026年11月12日決定。今のところ法人化の予定なし）
  - 背景：App Review Guidelines 5.1.1(ix) は、医療などの規制の多い分野や機微な個人情報が必要なアプリは「法人が提出するべき（should）」としている。本アプリが当たるとAppleが判断するかは確認できないため、まず個人で申請し、差し戻されたら下の「差し戻されたとき」に進む。出典：https://developer.apple.com/app-store/review/guidelines/
  - 差し戻されにくくする工夫：カテゴリは「ライフスタイル」のみ（ヘルスケア・メディカルは選ばない）／審査メモで「医療サービスではない・データを預からない・計測しない」を説明（`appstore/review_notes.md`）
- ☐ Apple Developer Program に**個人**で登録（年会費 99米ドル。円での金額は Apple の購入画面で確認）。個人は D-U-N-S 番号不要。
  - 注意：App Store の販売者名に**本名**が表示される。出典：https://developer.apple.com/programs/enroll/
- ☐ 差し戻されたとき（5.1.1(ix) を理由にした場合）の代案を決めておく：法人（株式会社・合同会社など）を作る、または法人の協力者（介護事業者など）から出してもらう。費用・期間は追加調査が必要。屋号（個人事業）では法人として登録できない。
- ☐ 医療機器に当たらないことの確認（法務）。**個人で出す場合も必要**（薬機法は個人にも適用される）。不安が残る場合は厚労省・PMDA の一元化窓口に相談。出典：プログラムの医療機器該当性に関するガイドライン（2021年3月31日）https://www.pmda.go.jp/files/000240364.pdf
- ☐ 商標「みんなのきょう」の調査（J-PlatPat）と出願の判断（法務）。**個人で出す場合も必要**（個人でも出願できる）
- ☑ 家族間の共有の方式を決めて実装（CloudKit の共有＋8けたの招待コード。`docs/ARCHITECTURE.md`）※ビルド・実機テスト前
- ☑ 招待コードは8けたに決定（2026年11月12日）
- ☐ 参加の承認（作成者が一人ずつ承認するか）を決める（法務・当事者家族）

## C. App Store Connect の準備
- ☐ アプリを登録（名前：みんなのきょう 認知症の家族向け）
- ☐ サブタイトル・キーワード・説明文：`appstore/metadata_ja.md` を貼る
- ☑ 説明画像 5枚（2868×1320px）：`appstore/screenshots/`
- ☑ アイコン（通常・ダーク・色合い）：`Assets.xcassets/AppIcon.appiconset`
- ☐ プライバシーポリシーの URL（`docs/PRIVACY_POLICY.md` を法務確認後に公開）
- ☐ サポート URL（問い合わせ先のページ）
- ☐ App のプライバシー（栄養成分ラベル）：開発者がデータを集めない設計なら「データの収集なし」。共有方式で変わる（法務・iOS）
- ☑ プライバシーマニフェスト（`PrivacyInfo.xcprivacy`）。使っているAPIが増えたら更新
- ☐ 年齢区分の質問に回答
- ☐ 価格を「無料」に設定（v1 は App 内課金なし。有料化は `docs/PRICING_FUTURE.md`）
- ☐ 審査メモ：`appstore/review_notes.md`（審査用のデモ用家族グループの入り方を書く）
