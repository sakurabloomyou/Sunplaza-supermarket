## 1. キャラクター

### キャサリン（主人公／大阪弁）
| 項目 | 設定 |
|---|---|
| 年齢 | 30代前半 |
| 職業 | OL（月〜金 9:00〜18:00） |

| 口ぐせ | 「ほんま、なんでやねん」「知らんけど」「〜やんか」「せやかて」「ええ感じやん」「そんなわけで今日は〜作ろかな」 |
| 決め台詞（締め） | 「どういうこっちゃ！」 |
| 衣装 | 通勤服 → 帰宅後エプロン（エプロンを巻く動作は毎回のお約束） |

**大阪弁の濃さルール（v0.5 追加）**
- 方言は1文に1〜2か所まで。説明（分量・手順）は聞き取りやすさ優先で、ほぼ標準語寄りにする
- 濃くするのは、ツッコミ・愚痴の山場・決め台詞だけ（「旅行行ってたんか！」「どういうこっちゃ！」など）
- 「〜ねん」を続けて使わない。「ほんでな」「〜な」の前置きを多用しない
- 「目ぇ」「火ぃ」「けえへん」「よろしゅう」など、濃すぎる言い方は使わない

**大阪弁の言い換えルール（台本チェック用）**
| 標準語 | 大阪弁 |
|---|---|
| 〜だよね | 〜やんな |
| 〜じゃない | 〜ちゃう／〜へん |
| とても | めっちゃ／えらい |
| 本当に | ほんま |
| 〜しておく | 〜しとく |
| 疲れた | しんどい／えらいわ |
| 〜しよう | 〜しよ／〜しよか |
| 〜だから | 〜やから |

### ジョージ（夫／標準語）
| 項目 | 設定 |
|---|---|
| 言葉 | 標準語（穏やか・爽やか） |

**ジョージの褒め言葉ストック（毎回ローテーション）**

2. 月が二つに見えるくらい美味しいよ！
3. 明日が昨日になるくらい美味しいよ！
4. 富士山が正座するくらい美味しいよ！
5. 重力が遠慮するくらい美味しいよ！
6. 信号が全部青になるくらい美味しいよ！
7. 太陽が二度寝するくらい美味しいよ！
8. 海が甘口になるくらい美味しいよ！

**一人ボケ・小ネタのルール（v0.2 追加）**
- 調理パートに **一人ボケ／小ネタを2〜3個** 入れる（目安：1分に1回）
- 型A「一人ボケ→自分でツッコむ」：例「これ泣いてんのちゃうで、玉ねぎのせいや…いや課長のせいかもしれん」
- 型B「視聴者への問いかけ」：例「コンタクトしてた時は全然平気やったのにICLしてから弱なった。みんなどう対策してんの？」→ テロップ「コメントで教えて！」（コメント欄を盛り上げる狙い）
- 型C「生活あるある」：OL・30代・夫婦生活のあるある
- 小ネタはあなたから指示があれば優先。なければこちらで作成

## 2. ビジュアル

### 共通
- **質感**: ファッションドール風（つややかなプラスチック肌、すらりとした等身、くっきりした目元）
- **世界観**: ドールハウス風のスーパー・キッチン（クリーム〜パステル基調。参照画像の背景色に合わせる）
- **食材・料理**: 背景はドール世界、料理だけ湯気・照り・焼き色が妙にリアル（ギャップの笑い）
- **テロップ**: 丸ゴシック、大阪弁部分を強調色（ピンク）で

### 衣装ルール
- 顔・髪型・固定の小物（キャサリン＝パール、ジョージ＝ネッカチーフと腕時計）は**変えない**。服とエプロンだけ毎回変える
- 1話の中ではキャサリンが「通勤服→（帰宅）→エプロン」、ジョージは「帰宅時の服」1着
- 季節を合わせる（公開月に合った素材・色）
- 二人の服の色をどこか一か所そろえる（夫婦リンクコーデ）と、毎回の小さな見どころになる
- 指示がなければ下のストックからこちらで選ぶ。使った衣装は「衣装の記録」に書き足して、かぶらないようにする

## 3. 本編フォーマット（合計 5:00 以内）

| 時間 | パート | 内容 |
|---|---|---|
| 0:00–0:05 | タイトル | チャンネルロゴ＋料理名 |
| 0:05–1:00 | ① 買い出し×愚痴 | 会社であったことを愚痴りながらスーパーで食材をカゴへ。愚痴と食材をつなげる（例：「上司の話、長すぎてネギも伸びるわ」） |
| 1:00–1:10 | ② 宣言 | 帰宅→「そんなわけで今日は〇〇を作ろかな」→エプロンを巻く |
| 1:10–4:20 | ③ 調理 | 材料紹介→工程（目安4〜6工程）。ツッコミと小ボケを挟む |
| 4:20–4:30 | ④ 盛り付け | 完成カット |
| 4:30–5:00 | ⑤ ジョージのオチ | ジョージ帰宅→一口→「〇〇くらい美味しいよ！」→キャサリン「どういうこっちゃ！」→終了 |

**セリフ量の目安**: 1分あたり約280〜300字（※一般的な読み上げ速度の目安。実際の音声で要実測）

## 5. 制作の進め方
1. あなたが「レシピ」と「愚痴内容」を `episode_request_template.md` の形式で送る
2. こちらが `episodes/epXXX_料理名.md` として台本一式を作成
   - 秒単位のタイムライン
   - セリフ（大阪弁／ジョージは標準語）
   - テロップ
   - カットごとの映像指示（動画生成AI・アニメ制作者向けプロンプト付き）
3. 動画ファイルそのものの生成はこの環境ではできません。台本を動画生成ツールや編集者に渡して制作してください
