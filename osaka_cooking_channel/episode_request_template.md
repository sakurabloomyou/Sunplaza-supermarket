# 回ごとの指示テンプレート（これを埋めて送ってください）

```
【回の種類】本編 ／ 番外編（ジョージが料理）
【料理名】
【材料（何人分）】
【作り方】
  1.
  2.
  3.
【コツ・ポイント】（あれば）
【愚痴の内容】（会社で何があったか。人物・出来事・オチ）
【ジョージの褒め言葉】（指定なし→ストックから自動選択）
【入れたい小ネタ】（任意）
```

## 記入例
```
【回の種類】本編
【料理名】豚こま生姜焼き
【材料（2人分）】豚こま200g、玉ねぎ1/2、生姜チューブ小さじ2、醤油大さじ2、みりん大さじ2、酒大さじ1
【作り方】
  1. 玉ねぎを薄切り
  2. 豚肉に片栗粉をまぶす
  3. 焼いて玉ねぎを加える
  4. 合わせ調味料を絡める
【愚痴の内容】課長が会議で同じ話を3回した。しかも3回目に「初めて言うけど」と前置きした
```
